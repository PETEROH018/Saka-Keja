# Saka-Keja

A full-stack web application designed to streamline property search and management.

## 🛠️ Tech Stack
* **Frontend:** React, HTML, CSS
* **Backend:** Python, Flask, RESTful APIs
* **Database:** SQL / SQLAlchemy

## ✨ Features
* User-friendly property search interface.
* Secure backend endpoints for managing listings and user data.
* Responsive design for seamless navigation.

## 🚀 Getting Started
1. Clone the repository: `git clone https://github.com/SantanaSCW/Saka-Keja.git`
2. Set up the backend environment and install dependencies.
3. Run the application locally to test.
